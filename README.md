# Kasir Sweet Olla

Aplikasi kasir toko Sweet Olla (PWA). Data tersimpan di perangkat, tidak dikirim ke server.

Buka tautan GitHub Pages di Safari (iPad/iPhone) atau Chrome (Android), lalu **Add to Home Screen** / **Tambahkan ke Layar Utama** agar muncul ikon aplikasi.

Setelah dipasang, aplikasi bisa dipakai tanpa internet.
